## 🚀 Proyectos y prácticas

Estos son los proyectos que quiero desarrollar y documentar durante mi formación en ASIR.

### 🐧 1. Linux Server Lab
Prácticas de instalación y administración de un servidor Debian en una máquina virtual.

**Temas:** usuarios, terminal, configuración del sistema y gestión de servicios.

### 🔐 2. SSH Security Lab
Prácticas de configuración de acceso remoto seguro a un servidor Linux.

**Temas:** OpenSSH, autenticación mediante claves, usuarios y configuración de seguridad.

### 🌐 3. Network Administration
Ejercicios de configuración y diagnóstico de redes en entornos Linux.

**Temas:** direccionamiento IP, interfaces de red, conectividad y modos de red en máquinas virtuales.

### ⚙️ 4. Bash Automation
Scripts para automatizar tareas habituales de administración de sistemas.

**Temas:** variables, funciones, condiciones, bucles y gestión de archivos.

> Los proyectos se irán publicando en GitHub a medida que avance en las prácticas y los documente.
